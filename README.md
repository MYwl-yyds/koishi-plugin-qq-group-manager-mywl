# 全方面QQ群管（koishi-plugin-qq-group-manager-mywl）

一个功能完整的 Koishi 群管理插件，适配 **OneBot v11** 协议（兼容 **NapCat / LLBot / go-cqhttp** 等标准 OneBot 实现）。提供禁言、踢出、退群、入群审核、举报、精华消息、群头衔、黑名单、白名单、违禁词、禁发链接、禁发指定图片、群员检查、权限组、配置导出导入等能力，支持全局配置与群级覆盖，内置 WebUI 管理台与统一 AI（OpenAI 兼容）接口。

## 特性概览

- **中文命令**：所有命令均为中文，可通过自定义权限组控制。
- **OneBot v11 适配**：统一封装 `set_group_ban`、`set_group_kick`、`set_group_leave`、`set_group_add_request`、`set_friend_add_request`、`set_essence_msg`、`set_group_special_title`、`get_stranger_info`、`get_group_member_list`、`get_group_list` 等内置接口，均通过标准 OneBot v11 协议调用，NapCat / LLBot / go-cqhttp 通用。
- **三级配置**：`Schema 默认 → 全局覆盖 → 群级覆盖`，均持久化到数据库，可在 WebUI 修改。违禁词 / 禁发链接 / 禁发图片可逐群选择「继承全局」或独立配置。
- **目标用户识别**：所有针对用户的操作（禁言、解除禁言、踢出、黑名单、白名单、头衔、权限组成员）均支持 `@用户` 或直接填写 `QQ 号`。
- **入群审核流水线**：频率检查、黑名单检查、QQ 等级检查、关键词检查、人工审核、LLM 自动处理，六步各自独立开关与参数。
- **群员检查**：**纯群级配置**（无全局开关），每个群独立设置扫描间隔与调度参数；按「QQ 账号等级 / 群名片 / 群等级」三类规则各自独立判定，每类可分别设置「禁言 / 踢出 / 仅记录」及通知模板。
- **禁发链接**：检测群消息中的网址并处罚，白名单支持完整链接、域名与泛域名（`*.example.com`），全局与群级白名单各自独立。
- **禁发指定图片**：以感知哈希（pHash）做「以图搜图」，命中样本库即处罚；样本库分「全局样本」与「群专属样本」两级；纯 JS 实现，无第三方图片依赖。
- **细粒度权限组**：每个命令与 WebUI 管理动作都有独立权限项（共 21 项，按功能域分组），支持优先级、默认组、生效群、成员管理、从群导入管理员/成员；查看与增删权限分离，高危项默认关闭。
- **通知转发**：将机器人收到的入群申请、邀请入群、加好友申请统一转发到指定私聊/群聊，**超级管理员「引用回复」并发送 `同意(y)` / `拒绝(n)` 即可处理**。
- **WebUI**：总览、群聊管控、名单中心、记录中心、系统五大分区共 11 个页面，按域按需取数 + 本地缓存，切页即时呈现。
- **导出导入**：配置（全局 + 群级 + 权限组）与黑白名单可分别导出为 JSON 并支持合并/替换两种导入模式，便于备份与跨环境迁移。
- **统一 AI 接口**：OpenAI 兼容格式，可自定义 baseURL / apiKey / model / temperature / max_tokens / 超时 / 各场景提示词，并内置连通性测试。
- **完善日志**：操作日志、审核日志、违规日志、黑名单变更日志，支持服务端分页与关键字检索。

## 安装与运行

### 依赖

- `koishi` `^4.18.0`
- 数据库插件（如 `@koishijs/plugin-database-sqlite`）——用于持久化配置与日志
- `@koishijs/plugin-console`（可选，用于 WebUI）
- OneBot 协议端（NapCat / LLBot / go-cqhttp 等）

### 安装

```bash
npm install koishi-plugin-qq-group-manager-mywl
```

### 构建（源码开发时）

```bash
npm install
npm run build        # tsc -b 编译后端到 lib，koishi-console build 编译前端到 dist
```

### 在 Koishi 中启用

1. 在控制台「插件市场」搜索并启用 `qq-group-manager-mywl`；
2. 插件的 Koishi 配置页只保留「群管功能总开关」「超级管理员 QQ」「OneBot 框架适配」三项极简配置；
3. 其余全部功能进入控制台侧边栏的「全方面QQ群管」页面进行可视化配置（总览 / 群聊管控 / 名单中心 / 记录中心 / 系统）。

> 注意：OneBot 相关部分框架使用 AGPL 协议，使用 `@koishijs/plugin-adapter-onebot` 运行机器人时请知悉相关开源约束。

## 命令说明

所有命令均可通过自定义权限组控制；**未创建任何权限组时仅超级管理员可触发命令**，创建权限组后按权限组配置执行。下表 `<用户>` 表示既可使用 `@用户` 提及，也可直接填写 QQ 号。

### 基础群管

| 命令              | 说明                                         |
| --------------- | ------------------------------------------ |
| `禁言 <用户> [时长]`     | 禁言指定用户，默认 10 分钟；时长支持单位 `s`/`m`/`h`/`d`（如 `1h`=1 小时、`30s`=30 秒、`1d`=1 天，也支持中文：秒/分/分钟/时/小时/天/日） |
| `解除禁言 <用户>`        | 解除指定用户禁言                                   |
| `全体禁言`          | 开启当前群全体禁言                                   |
| `全体解禁`          | 关闭当前群全体禁言                                   |
| `踢出 <用户>`          | 将指定用户移出群聊                                  |
| `退群`            | 机器人退出当前群聊                                  |

入群申请、邀请入群、加好友申请均通过「通知转发」或「人工审核通知」统一处理，**超级管理员 / 审核员只需「引用回复」通知并发送 `同意`(y) / `拒绝`(n) 即可完成审批**，无需使用命令。

| `取消头衔 <用户>`       | 取消群专属头衔                      |

### 权限项一览

每个命令与管理动作都有**独立的权限项**（WebUI 的「权限管理」按功能域分组展示，带 `!` 标记的是高危项，默认关闭）：

| 分组 | 权限项 |
| --- | --- |
| 成员管理 | `禁言` `解除禁言` `全体禁言` `全体解禁` `踢出` `退群` **!** |
| 入群审核 | `审核员` **!** |
| 举报 | `举报` **!** |
| 内容管理 | `设置精华` `取消精华` `设置头衔` `取消头衔` `违禁词查看` `违禁词管理` `违规图管理` |
| 名单管理 | `黑名单查看` `黑名单管理` `白名单查看` `白名单管理` |
| 系统 | `权限组查看` **!** `权限组管理` **!** |

- **默认放行**：`禁言`、`解除禁言`、`全体禁言`、`全体解禁`、`踢出`、精华与头衔相关，以及全部名单与违禁词的查看/管理项；
- **默认拒绝**（高危，新建权限组时不会自动获得，必须在 WebUI 显式勾选）：`退群`、`审核员`、`举报`、`权限组查看`、`权限组管理`；
- **查看与管理已分离**：只读命令（`违禁词列表`、`违规图列表`、`黑名单列表`、`白名单列表`）用「查看」权限，增删操作才需要「管理」权限 —— 可以只给某人查看名单的权限而不给他增删权；
- 升级说明：旧版本使用 `添加违禁词` / `移除违禁词` / `添加黑名单` 等权限项。插件读取时会**自动兼容旧项**（旧项为开则对应新项视为开），因此升级后不会出现「权限突然全部失效」，但建议到「权限管理」页面确认一遍并按新分组重新勾选。

## 配置说明

配置分三层（优先级从高到低）：群级覆盖 → 全局覆盖 → Schema 默认值。

### 入群审核流程

检测到入群申请后按固定顺序执行（每步独立开关，**未开启的步骤自动跳过**，命中拒绝的步骤立即终止并拒绝）：

1. **频率检查**：在 `windowMinutes` 分钟内申请超过 `maxCount` 次则拒绝；
2. **黑名单检查**：申请人 QQ 在黑名单中则拒绝；
3. **QQ 等级检查**：通过 `get_stranger_info` 读取等级，低于 `minLevel` 则拒绝（接口不可用时自动降级跳过）；
4. **关键词检查**：申请内容命中「拒绝关键词」则拒绝、命中「通过关键词」则通过；
5. **人工审核**：通知发送至「入群自动判定结果通知」配置的目标（目标为空时默认发送至事件所在群），拥有「审核员」权限的用户可「引用回复」审核通知发送 `同意` / `拒绝`（或 `y` / `n`）完成审批；
6. **LLM 自动处理**：人工审核超时（或未启用人工审核）后调用 AI 自动审批；
7. **默认操作**：仅在所有审核判定失效或超时后执行，可选「同意」或「拒绝」。

每个流程步骤均可单独配置「拒绝理由」，拒绝入群申请时自动提交该理由。「审核员」已从群聊管理中移除，作为权限项在「权限管理」中统一开关（超级管理员始终可审核）。

### 通知转发（请求通知统一转发）

开启后可把机器人收到的「入群申请 / 邀请入群 / 加好友申请」统一转发到指定私聊或群聊（目标不能是已在「群聊管理」中配置的群）。通知中不再展示 `flag`，处理方式为：**超级管理员「引用回复」转发出来的那条通知，发送 `同意`(y) / `拒绝`(n) 即可处理**；若同意好友申请后未填写备注、或拒绝后未填写理由，则不附带备注/理由。

支持自定义转发内容格式，变量见下方「模板变量说明」。

### 举报功能

`举报` 命令需要「举报」权限项（**默认关闭**，需在「权限管理」中显式勾选），系统提取被引用消息与上下文，调用 AI 判断是否违规、违规类型与程度，并执行惩罚：

> ⚠️ 举报会触发 AI 判定并可能执行**撤回 / 禁言 / 踢出**，因此不再对所有群成员开放。
> 如需允许普通成员举报，请在「权限管理 → 举报」中为对应权限组勾选该项；超级管理员始终可用。

- 是否撤回 / 是否踢出仍由「惩罚映射」决定（轻度=撤回、中度=撤回+禁言、重度=撤回+踢出，可自定义）；
- **禁言时长由 LLM 自定义**（通过审核结果中的 `muteDuration` 字段，单位分钟），未提供时回退到映射中的禁言时长，**最长不超过 2 小时（120 分钟）**；
- **频率限制**：可在「群聊管理」中设置，窗口时间（分钟）内最多举报次数，超出则提示频率过快。

### 违禁词功能

- 支持多个违禁词；触发后可选择禁言 / 踢出 / 撤回（禁言与踢出互斥）；可自定义禁言时长；可设置白名单豁免。

### 禁发链接

在「群聊管控 → 违禁词与链接」中开启「禁发链接」后，插件会检测群消息中的网址并按配置处罚：

- **识别范围**：`http(s)://` 完整链接、`www.` 开头、IPv4（含端口）、以及常见顶级域名的裸域名（如 `example.com/xx`）；
- **白名单**支持三种写法，可混用：
  - 完整链接：`https://example.com/ok`（按路径前缀匹配，该路径及其子路径放行）；
  - 域名：`example.com`（放行 `example.com`、`www.example.com` 与任意子域名）；
  - 泛域名：`*.example.com`（放行任意子域名，不含 `example.com` 本身）；
- **处罚**：可独立设置撤回 / 禁言 / 踢出与禁言时长，禁言与踢出互斥（同时开启时以禁言为准）；
- 页面提供「试一试」输入框，可实时验证某条链接是否会被放行，判定逻辑与运行时完全一致；
- 白名单用户（勾选「豁免违禁词」）不受禁发链接处罚。

### 禁发指定图片

在「群聊管控 → 违禁词与链接」中开启「禁发指定图片」后，插件会把群消息里的图片与**违规图样本库**做比对，命中即按配置处罚。

**检测方式：感知哈希（pHash）以图搜图**

1. 把样本图和待检图片统一缩放为 32×32 灰度图；
2. 做二维 DCT，取左上 8×8 低频系数（跳过直流分量）得到 63 位指纹；
3. 用汉明距离衡量两张图的差异，距离 ≤ 阈值即判定为同一张图。

阈值越小越严格：`0` 要求几乎完全一致；`8`（默认）可容忍转发压缩、轻微缩放和二次保存；超过 `16` 误判率明显上升，不建议。

- **两级样本库**：
  - **全局样本**（在「违禁词与链接」页面维护）对所有群生效；
  - **群专属样本**（在「群配置详情 → 禁发指定图片」中维护）只对该群生效；
  - 某群实际比对的样本 = 全局样本 + 本群专属样本，去重按「哈希 + 归属」判定，同一张图可以既是全局样本又是某群样本；
- **样本录入**：WebUI 可粘贴图片地址或上传本地图片，群内可引用图片后发送 `设为违规图` 采集（采集到该群）；
- **格式支持**：PNG 与基线 JPEG（纯 JS 解码，无第三方依赖，不引入原生模块）；WebP / GIF / 渐进式 JPEG 暂不支持，请转成 PNG 后再入库；
- **处罚独立**：撤回 / 禁言 / 踢出与禁言时长可单独设置，与违禁词、禁发链接互不影响；
- 通知模板变量额外支持 `{distance}`（命中的汉明距离）与 `{image}`（图片地址）。

### 违禁词 / 链接 / 图片的群级覆盖

这三块都可以**按群单独配置**，在「群配置详情」中各有独立的「继承全局」开关：

| 勾选状态 | 行为 |
| --- | --- |
| **勾选「继承全局」** | 本群沿用「违禁词与链接」页面的全局设置；保存时不写入任何相关字段 |
| **取消勾选** | 可以为该群单独设置开关、处罚规则与白名单，完全独立于全局 |

注意事项：

- 「继承全局」只表示**本次保存不再写入新值**，并不会删除本群此前存过的独立配置。如果某群之前自定义过，页面会给出提醒；
  要真正恢复为全局设置，请点该群配置页顶部的「重置为全局」。
- 禁发链接的白名单、禁发图片的样本库都是**按归属隔离**的：群级白名单只对该群生效，群级样本只对该群生效。

### 群员检查

> **群员检查是纯群级配置**：没有全局开关，每个群一份独立设置，互不影响、也不跟随任何全局值。
> 可以在「群聊管控 → 群配置详情」或「群聊管控 → 群员检查」页面按群配置。

在「群聊管控 → 群员检查」中配置（先选择群聊），支持定时自动扫描与手动立即检查：

| 检测项 | 触发条件 | 可设置 |
| --- | --- | --- |
| **检测等级** | 成员 QQ 账号等级低于指定值 | 最低等级、QQ 等级获取失败时的处理（跳过 / 视为命中） |
| **检测群名片** | 成员群名片包含 / 完全等于指定内容 | 匹配模式、关键词列表（支持 `/正则/`）、是否区分大小写、是否排除管理员、是否排除白名单 |
| **检测群等级** | 成员群等级（群活跃等级）低于指定值 | 最低等级、群等级获取失败时的处理（跳过 / 视为命中） |

- **触发操作按检测项分别设置**，每项可选 `禁言`（自定义时长）/ `踢出` / `仅记录`（只写日志不做处理）；
- 每项均可单独配置通知模板，变量支持 `{userId}` `{nickname}` `{card}` `{level}` `{word}` `{threshold}` `{punish}` `{reason}`；
- **扫描调度也是群级的**：每个群可独立设置扫描间隔（分钟）、单群超时（秒）、并发请求数、冷却时间（小时）与活跃范围；
  定时器每 60 秒检查一次，挑出「本群自己的间隔已到」的群分别执行，各群互不干扰；
- **扫描范围**：仅检查最近 N 天内活跃过的成员（`0` 表示不限）；机器人自身与超级管理员自动跳过；群名片检查中群主/管理员与白名单成员可豁免；
- **去重冷却**：同一成员在冷却时间内不会重复处罚，避免反复禁言/踢人；
- **手动检查**：「立即全量检查」扫描所有已启用群员检查的群，「对该群立即执行检查」只跑当前选中的群；「预览命中成员」不执行任何操作，仅列出会命中的成员；
- 群等级优先取自 `get_group_member_list` 返回的 `level` 字段，缺失时逐个调用 `get_group_member_info` 补齐；QQ 账号等级通过 `get_stranger_info` 获取（该字段来自 LLBot / NapCat 的扩展实现，接口不可用时按「获取失败」配置处理）。

### 黑名单 / 白名单

- 黑名单、白名单均支持「全局」与「分群」两级；各群**默认使用本群独立名单**，可在「黑/白名单」页面按群勾选「应用全局黑名单/白名单」改用全局名单，也可一键「转移全局」。
- 命令默认操作本群名单，加 `-q` 操作全局名单（添加/移除均支持）。
- 白名单用户可分别豁免被举报、入群审核、违禁词。

### 退群自动拉黑

- 监听群成员减少事件，可分别配置是否拉黑「主动退群者」与「被踢出者」；
- 支持延迟执行、拉黑通知；记录黑名单变更日志。

### AI 接口

所有需要 LLM 的功能（入群自动处理、举报审核）统一使用此接口配置：

- `baseURL`（OpenAI 兼容）、`apiKey`、`model`、`temperature`、`max_tokens`、`timeout`；
- 「入群审核提示词」只需填写自定义要求，系统自动将其与**系统提示词**（身份说明 + JSON 输出格式，内容固定）合并；「举报审核提示词」默认已填入推荐内容，留空则使用默认提示词；
- 接口失败或返回无法解析时：入群审核判定失效（落入「默认操作」）、举报默认不违规，不会中断主流程。

## 模板变量说明

插件中所有支持变量的通知 / 文案功能，可用模板变量如下（使用时以 `{变量名}` 形式嵌入文本）：

| 变量 | 含义 | 适用功能 |
| --- | --- | --- |
| `{userId}` | 用户 / 成员 QQ 号 | 欢迎欢送、入群判定通知、违禁词通知、退群拉黑通知、通知转发 |
| `{groupId}` | 群号 | 欢迎欢送、入群判定通知、违禁词通知、退群拉黑通知、通知转发（好友申请时为空） |
| `{nickname}` | 用户 / 成员昵称 | 欢迎欢送、入群判定通知、违禁词通知、退群拉黑通知、通知转发 |
| `{level}` | QQ 等级 | 欢迎欢送、入群判定通知、违禁词通知、退群拉黑通知（为空时整行省略） |
| `{avatar}` | QQ 头像图片 | 欢迎欢送、入群判定通知、违禁词通知、退群拉黑通知 |
| `{groupName}` | 群聊名称 | 入群判定通知、违禁词通知、退群拉黑通知 |
| `{groupIntro}` | 群聊简介 | 入群判定通知、违禁词通知、退群拉黑通知（为空时整行省略） |
| `{groupAvatar}` | 群聊头像图片 | 入群判定通知、违禁词通知、退群拉黑通知 |
| `{memberCount}` | 群人数 | 入群判定通知、违禁词通知、退群拉黑通知（为空时整行省略） |
| `{answer}` | 申请回答内容 | 入群判定通知（为空时整行省略） |
| `{result}` | 判定结果（同意 / 拒绝） | 入群判定通知 |
| `{reason}` | 审核理由 / 拉黑原因 | 入群判定通知、退群拉黑通知 |
| `{word}` | 触发的违禁词 / 命中的关键词 | 违禁词通知（含禁发链接）、群员检查通知 |
| `{punish}` | 处罚结果（撤回 / 禁言 / 踢出） | 违禁词通知（含禁发链接）、群员检查通知 |
| `{card}` | 群名片 | 群员检查通知 |
| `{threshold}` | 检测阈值 / 匹配方式 | 群员检查通知 |
| `{host}` | 命中的链接域名 | 禁发链接通知 |
| `{link}` | 命中的完整链接 | 禁发链接通知 |
| `{distance}` | 图片比对命中的汉明距离（越小越相似） | 禁发图片通知 |
| `{image}` | 命中图片的地址 | 禁发图片通知 |
| `{title}` | 申请类型标题（加好友申请 / 入群申请 / 邀请入群） | 通知转发 |
| `{comment}` | 申请内容 / 附言 | 通知转发 |

> 说明：`{answer}`、`{level}`、`{groupIntro}`、`{memberCount}` 变量为空时，包含该变量的整行会自动省略；`{avatar}` 会渲染为 QQ 头像图片，`{groupAvatar}` 会渲染为群头像图片。所有功能已统一变量命名（例如欢迎欢送语不再使用 `{user}`/`{group}`，统一为 `{userId}`/`{groupId}`）。

## WebUI 使用

启用 `@koishijs/plugin-console` 后，在控制台侧边栏会新增「全方面QQ群管」入口。该入口仅对权限等级 ≥ 3 的管理员账号可见（需要 `@koishijs/plugin-auth`）；未启用 auth 插件时无权限过滤，默认对所有人显示。

页面按功能重新划分为五大分区，共 11 个页面。其中「违禁词与链接」是**全局默认值**页面，各群的具体行为在「群配置详情」中按需覆盖：

**📊 总览**

1. **总览**：已配置群数/权限组数/违禁词数/待审核数/黑名单数统计卡片，近 N 天日志趋势曲线、违规类型分布、群员检查运行状态（已启用的群数与各检测项分布）、待审核申请（可一键通过/拒绝）、最近日志；数据 30 秒自动刷新。

**💬 群聊管控**

2. **群聊列表**：选择或批量添加群聊（自动读取机器人所在群并带出群名），展示各群功能开关生效状态、名单数量，支持一键重置/删除配置；
3. **群配置详情**：按群配置欢迎语/欢送语/入群审核/违禁词/禁发链接/禁发指定图片/群员检查/举报/精华/头衔/退群拉黑/AI 接口。违禁词、链接、图片三块各有「继承全局」勾选；群员检查为纯群级配置，不参与全局继承；
4. **违禁词与链接**：违禁词增删与处罚设置，**禁发链接**（处罚规则 + 全局链接白名单 + 「试一试」验证）和**禁发指定图片**（全局样本库管理、阈值、比对测试），三套通知模板独立配置；
5. **群员检查**：先选择群聊，再配置该群的**三项检测**（QQ 等级 / 群名片 / 群等级）开关、阈值、匹配模式与**各自独立的触发操作**，以及该群专属的扫描间隔、超时、并发、冷却与活跃范围；支持预览命中成员与对单群/全部群立即执行检查。

**📋 名单中心**

6. **黑名单**：全局/分群黑名单管理，支持批量添加、移除、转移全局、「应用全局黑名单」开关；
7. **白名单**：全局/分群白名单管理，支持批量添加、移除、转移全局，以及豁免被举报 / 入群审核 / 违禁词（含禁发链接与禁发图片）三项独立开关。

**🗂 记录中心**

8. **操作记录**：按类型（操作/审核/违规/黑名单）、时间范围与关键字检索，服务端分页 + 可调每页条数，日志明细可展开查看 JSON。

**⚙️ 系统**

9. **权限管理**：权限组增删、默认组/优先级、**按功能域分组的权限开关**（支持整组「全开/全关」，高危项带 `!` 标记）、成员批量管理、生效群聊配置、按「群号+角色（管理员/成员/群主）」快捷导入成员；
10. **全局设置**：超级管理员、协议端状态、通知转发（含自定义转发内容格式）、AI 全局接口设置与**连通性测试**；
11. **导出与导入**：配置（全局设置 + 群级覆盖 + 权限组）与黑名单 / 白名单分别导出为 JSON 文件，导入支持「合并」与「替换」两种模式。

> 说明：
> - WebUI 中的「全局设置」「群配置详情」写入的是全局/群级覆盖配置，优先级高于插件 Schema 配置面板中的默认值；
> - 所有批量添加框均支持逗号 / 空格 / 分号 / 换行分隔；
> - 页面数据按「域」按需加载（总览 / 群列表 / 群详情 / 名单 / 日志 / 权限 / 设置 / 群员检查），任一操作只刷新受影响的域，切换页面时优先展示本地缓存内容并后台静默更新，顶部会显示「x 秒前更新」；
> - 侧边栏可折叠，支持 6 套主题配色（靛蓝 / 翠绿 / 玫红 / 落日 / 海洋 / 暗色）。

### 配置与名单的导出 / 导入

在「系统 → 导出与导入」页面中操作：

- **配置导出**：包含全局设置、各群覆盖配置、权限组、**全局违规图样本**（仅哈希与备注，不含图片本体），导出为 UTF-8 JSON；**不含**黑白名单、群专属违规图样本，也不含日志与成员检查状态等运行数据；
  - 全局设置中的 `memberCheck` 会被剔除（群员检查已是纯群级配置，导出它没有意义且容易误导）；
  - 各群的群级配置（含该群自己的 `memberCheck`、禁发链接/图片与群专属样本归属）随 `groups` 一起导出；
- **名单导出**：黑名单与白名单分别导出，白名单会保留三项豁免开关，黑名单条目保留来源与添加时间；
- **导入模式**：
  - **合并**：只覆盖文件中出现的字段，适合把 A 环境的配置补到 B 环境；违规图样本按「哈希 + 归属」去重，已存在的不会重复写入；
  - **替换**：权限组会先清空再写入，群级配置按文件整体覆盖，全局违规图样本也会先清空再写入 —— 不可撤销，建议先导出一份当前配置作为备份；
- 导入时会校验文件标识与版本号，非本插件导出的文件会被拒绝；名单导入会校验 QQ 号格式（5–12 位数字），非法条目会被跳过并计数；
- 导入黑名单会**绕过「白名单豁免」判断**，以忠实还原导出内容（即从文件恢复出的黑名单不会被现有白名单条目挡掉）。

## 异常与降级

- 未启用 AI（未配置 apiKey）时：举报返回提示、入群 LLM 步骤跳过；
- OneBot 协议端不是 v11（无 `internal`/`onebot` 接口）时：调用返回明确错误提示；
- QQ 等级接口不可用时：跳过等级检查而不误拦；
- 数据库缺表/不可写时：日志写入失败仅告警，不影响主流程。
